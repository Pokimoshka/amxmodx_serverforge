# AMX Mod X: Найденные проблемы и аномалии

## Критические проблемы (Priority: Critical)

### 1. Type Punning через union (UB в C++11+)
**Файлы:** amx.h, многие модули
**Описание:** Использование union для преобразования float <-> cell вызывает undefined behavior
**Статус:** ✅ ИСПРАВЛЕНО - создан bit_cast в type_utils.h

### 2. Утечка памяти в amxcore.cpp
**Файл:** amxmodx/amxcore.cpp, строка 217
**Код:**
```cpp
plist->stringlist = (char**)realloc(plist->stringlist, ...);
```
**Проблема:** При неудачном realloc теряется указатель на старый буфер
**Статус:** ✅ ИСПРАВЛЕНО - добавлена проверка перед перезаписью

### 3. Небезопасный realloc в CDataPack.cpp  
**Файл:** amxmodx/CDataPack.cpp, строка 71
**Код:**
```cpp
m_pBase = (char*)realloc(m_pBase, size);
```
**Проблема:** Аналогичная утечка памяти
**Статус:** ✅ ИСПРАВЛЕНО - добавлена проверка

### 4. Использование NULL вместо nullptr
**Файлы:** Весь проект (2000+ вхождений)
**Проблема:** Устаревший C-стиль, может вызывать проблемы с перегрузкой функций
**Статус:** 🔄 В РАБОТЕ - создан скрипт для замены

## Высокий приоритет (Priority: High)

### 5. C-style casts повсеместно
**Файлы:** Весь проект
**Примеры:**
- `(cell *)` - около 500 вхождений
- `(char *)` - около 300 вхождений  
- `(unsigned char *)` - около 150 вхождений
**Проблема:** Небезопасные приведения типов, скрывают ошибки
**Статус:** 🔄 В РАБОТЕ - создана утилита safe_ptr_cast

### 6. Макросы без type safety
**Файл:** amxmodx/amx.cpp
**Код:**
```cpp
#define GETPARAM(v)  ( v=*(cell *)(code+(int)cip), cip+=sizeof(cell) )
#define PUSH(v)      ( stk-=sizeof(cell), *(cell *)(data+(int)stk)=v )
#define POP(v)       ( v=*(cell *)(data+(int)stk), stk+=sizeof(cell) )
```
**Проблема:** Отсутствие проверок границ, небезопасные касты
**Статус:** ✅ ЧАСТИЧНО - добавлены проверки в DEBUG режиме

### 7. Отсутствие RAII
**Файлы:** Весь проект
**Проблема:** Ручное управление памятью с malloc/free, риск утечек
**Статус:** ✅ ИСПРАВЛЕНО - создан raii_wrappers.h

### 8. Небезопасное преобразование size_t <-> int
**Файлы:** Многие
**Примеры:**
```cpp
size_t len = strlen(str);
int ilen = (int)len;  // Потеря данных на 64-bit
```
**Проблема:** Потеря данных при работе с большими строками/буферами
**Статус:** 🔄 В РАБОТЕ - создан safe_cast

## Средний приоритет (Priority: Medium)

### 9. Отсутствие const correctness
**Файлы:** Многие функции
**Примеры:**
```cpp
char *get_amxstring(AMX *amx, cell amx_addr, ...);  // Should return const char*
```
**Проблема:** Можно случайно модифицировать внутренние данные
**Статус:** ⏳ ЗАПЛАНИРОВАНО

### 10. Неиспользуемые переменные и параметры
**Файлы:** Многие
**Примеры:**
```cpp
int func(int x, int y) {  // y never used
    return x * 2;
}
```
**Проблема:** Код-мусор, усложняет понимание
**Статус:** ⏳ ЗАПЛАНИРОВАНО

### 11. Смешанный стиль кодирования
**Файлы:** Весь проект
**Проблемы:**
- Смешаны табы и пробелы
- Непоследовательное именование (snake_case vs camelCase)
- Разный стиль скобок
**Статус:** ⏳ ЗАПЛАНИРОВАНО

### 12. Отсутствие noexcept спецификаторов
**Файлы:** Почти все
**Проблема:** Не указано какие функции могут бросать исключения
**Статус:** ⏳ ЗАПЛАНИРОВАНО

## Низкий приоритет (Priority: Low)

### 13. Устаревшие заголовки C
**Примеры:** string.h, stdio.h, stdlib.h
**Рекомендация:** Заменить на cstring, cstdio, cstdlib
**Статус:** ⏳ ЗАПЛАНИРОВАНО

### 14. Отсутствие move semantics
**Файлы:** Классы типа CDataPack, CVector
**Проблема:** Ненужное копирование
**Статус:** ✅ ЧАСТИЧНО - добавлено в RAII обертки

### 15. Глобальные переменные
**Файлы:** amxmodx.cpp и многие другие
**Примеры:**
```cpp
CPluginMngr g_plugins;
CTaskMngr g_tasksMngr;
// ... много других
```
**Проблема:** Усложняет тестирование и может вызывать race conditions
**Статус:** ⏳ ЗАПЛАНИРОВАНО - требует крупного рефакторинга

## Проблемы безопасности

### 16. Buffer overflows
**Файлы:** Многие, особенно при работе со строками
**Примеры:**
```cpp
char buffer[256];
strcpy(buffer, str);  // Нет проверки длины!
```
**Статус:** 🔄 В РАБОТЕ - требуется audit

### 17. Format string vulnerabilities
**Файлы:** Логирование, вывод ошибок
**Примеры:**
```cpp
printf(user_string);  // ОПАСНО! Должно быть printf("%s", user_string)
```
**Статус:** ⏳ ЗАПЛАНИРОВАНО - требуется audit

### 18. Integer overflow
**Файлы:** Арифметические операции с cell
**Примеры:**
```cpp
cell result = a + b;  // Может переполниться
```
**Статус:** ⏳ ЗАПЛАНИРОВАНО

## Функциональные улучшения
