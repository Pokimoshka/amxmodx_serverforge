## Приоритеты исправлений

### Критичность: СРОЧНО
1. Type punning в amx_ftoc/amx_ctof - UB может привести к краху
2. Утечки памяти в amxcore.cpp - критично для долгоживущих серверов
3. Небезопасный realloc - может привести к потере данных
4. Опасные макросы PUSH/POP - риск buffer overflow

### Критичность: ВЫСОКАЯ
1. C-style casts - снижают безопасность типов
2. NULL → nullptr - улучшает типобезопасность
3. void* типизация - повышает надежность
4. const-correctness - предотвращает случайные модификации

### Критичность: СРЕДНЯЯ
1. Умные указатели - предотвращают утечки
2. RAII-обертки - автоматическое управление ресурсами
3. Signed/unsigned конверсии - предотвращают overflow

### Критичность: НИЗКАЯ
1. Современные C++ практики - улучшают поддерживаемость
2. Exception safety - повышают надежность
3. Новый функционал - расширяют возможности
